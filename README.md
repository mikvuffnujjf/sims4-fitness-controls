## Overview

Fitness Controls gives players direct numerical slider control over Sim body weight and muscle tone in Create-A-Sim, with configurable workout effectiveness multipliers, calorie tracking, and realistic physique decay that erodes fitness without regular exercise, creating a genuinely consequential fitness simulation.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **The Sims 4 Fitness Controls** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Direct Sliders** | Numeric weight and muscle tone adjustment from any game mode |
| **Workout Multiplier** | Configurable effectiveness multiplier for all exercise interactions |
| **Fitness Decay** | Physique deteriorates over time without consistent exercise routine |
| **Calorie System** | Optional calorie intake tracking affects weight gain and loss rate |
